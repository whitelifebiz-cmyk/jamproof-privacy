Politique de confidentialité — JamProof

Résumé : JamProof ne collecte aucune donnée personnelle. Toutes vos données restent sur votre appareil.

1. Données collectées

JamProof enregistre uniquement les données GPS de vos trajets (vitesse, position, horodatage) directement sur votre appareil. Ces données ne sont jamais transmises à un serveur externe.

2. Utilisation des données

Les données GPS sont utilisées exclusivement pour générer votre rapport PDF de trajet. Elles ne sont pas partagées, vendues ou transmises à des tiers.

3. Stockage

Toutes les données sont stockées localement sur votre appareil dans une base de données SQLite. La désinstallation de l'application supprime définitivement toutes vos données.

4. Permissions requises

  • Localisation (GPS) — Nécessaire pour enregistrer votre trajet et mesurer votre vitesse.
  • Localisation en arrière-plan — Nécessaire pour continuer l'enregistrement lorsque l'écran est éteint.
  • Notifications — Utilisées pour le mode automatique (rappel de démarrage de trajet).

5. Partage des données

Le rapport PDF peut être partagé manuellement par l'utilisateur via les applications de partage Android (email, WhatsApp, etc.). Ce partage est entièrement sous le contrôle de l'utilisateur.

6. Enfants

JamProof ne collecte aucune donnée et ne cible pas les enfants de moins de 13 ans.

7. Modifications

Cette politique peut être mise à jour. La date de dernière modification est indiquée en bas de page.

8. Contact
